AWS VPC — Virtual Private Cloud

Amazon VPC is your own logically isolated network inside AWS, where you can deploy applications, databases and other cloud resources while controlling how they communicate.

Think of AWS as a large technology park and your VPC as your own private campus.

1. What does a VPC look like?

A VPC can span multiple Availability Zones within one AWS Region. Each individual subnet belongs to one Availability Zone.

5. What is a subnet?

A subnet is a smaller IP network inside a VPC.

Four non-overlapping subnet ranges within one VPC.

Public vs private vs isolated subnet

PublicDirect route to an IGW
Load balancers, public servers
PrivateNo direct internet gateway route
Application servers
IsolatedNo external network route
Internal databases

A subnet's routing configuration determines whether it is public or private, not its name.

6. What is an internet gateway?

An internet gateway provides a path between resources in your VPC and the public internet.

Direct internet connectivity requires routing, appropriate addressing and permissive security rules.

8. What is a NAT gateway?

A public NAT gateway allows private IPv4 resources to initiate internet connections without exposing those resources to unsolicited inbound internet connections.

AWS also supports regional NAT gateways, which simplify multi-AZ deployments.

21. Final interview answer

Amazon VPC is a logically isolated virtual network within AWS. It allows us to define IP address ranges, create public and private subnets, configure routing and control network access.

Internet gateways provide direct internet connectivity, while public NAT gateways allow private resources to initiate internet connections.

Security groups provide stateful resource-level security, and network ACLs provide stateless subnet-level security.

VPCs help us build secure, scalable and highly available cloud architectures across multiple Availability Zones.

22. Complete mental model

Remember: EC2 provides compute. RDS provides databases. VPC provides the network infrastructure that connects and protects them.
