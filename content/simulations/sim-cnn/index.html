How does a CNN learn its filters?

The filter above was hand-designed for teaching. In a real CNN, the network normally starts with adjustable weights and improves them by learning from labeled examples.

🖼️ExampleImage + label
🧠PredictCurrent weights
🎯ErrorCompare answers
↻ImproveUpdate weights

Training repeats this cycle using backpropagation and an optimizer. Later CNN layers combine simple edges and textures into richer patterns that can help recognize cats, cars, faces, or other objects.

Three words to remember

Filter (kernel)A small set of weights that detects local patterns.
Feature mapThe grid of responses produced by a filter.
PoolingKeeps important local values in a smaller grid.
Takeaway: A CNN learns reusable filters. They slide over images to create feature maps, then layers transform and combine those features to make predictions.
