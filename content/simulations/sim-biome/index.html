Biome — Frontend Code Quality Tool

Biome
Unified formatter, linter and code assist tool
biomejs.dev https://biomejs.dev/

Biome is a high-performance tool that helps frontend developers maintain clean, consistent and reliable code.

It combines responsibilities traditionally handled by multiple tools into one toolchain.

1. Why do we need Biome?

One tool and a shared configuration for multiple code-quality operations.

Biome can replace many common Prettier and ESLint workflows, although it does not provide exact compatibility with every rule, plugin or formatting option.

13. Important Biome commands

npx biome init
Create the configuration file.
npx biome format .
Check code formatting.
npx biome format --write .
Apply formatting.
npx biome lint .
Detect lint problems.
npx biome lint --write .
Apply available safe lint fixes.
npx biome check .
Run formatting, lint and assist checks.
npx biome check --write .
Apply formatting, safe fixes and assist actions.
npx biome ci .
Run code-quality validation in CI.

The --write flag modifies files. Review the resulting changes before committing them.

  "editor.defaultFormatter": "biomejs.biome",
  "editor.formatOnSave": true,
  "editor.codeActionsOnSave": {
    "source.fixAll.biome": "explicit",
    "source.organizeImports.biome": "explicit"
  }

Scope the default formatter to supported languages if your project uses other file types.

16. Biome in a GitHub CI/CD pipeline

Biome can validate your code before it is built and deployed.

Frontend CI simulator
Configure the condition of your source code.
Simulated CI workflow treating all selected issues as blocking errors. Actual diagnostic severity and pipeline configuration determine whether a build fails.

Example .github/workflows/quality.yml:

yaml
name: Code Quality

on: [push, pull_request]

jobs:
  biome:
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version: "22"

      - run: npm ci

      - run: npx biome ci .

17. Migrating from ESLint and Prettier

bash
npx biome migrate eslint --write
npx biome migrate prettier --write

Not every existing plugin or rule has an equivalent in Biome. Validate the migration before uninstalling your previous tools.

21. Interview answer

Biome is a high-performance code-quality toolchain for frontend development. It combines formatting, linting and assist operations into a unified solution.

It supports JavaScript, TypeScript, JSX, JSON and other web languages. It helps developers maintain consistent code, detect potential problems and organize imports.

Biome can replace many traditional ESLint and Prettier workflows and can be integrated with code editors and CI/CD pipelines.

22. Complete mental model

Many formatting and linting workflows unified into one tool.

Remember: React builds your UI. TypeScript checks types. Vite builds your application. Biome maintains your source-code quality.
