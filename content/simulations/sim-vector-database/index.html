Vector Database

Vector Database అనేది data లో ఉన్న meaning (అర్థం) ఆధారంగా similar information వెతికే database.

Traditional keyword search exact words కోసం search చేస్తే, Vector Database semantic similarity ఆధారంగా search చేయగలదు.

1. Data ఎలా store అవుతుంది?

Text → Embedding model → Numerical vector

Embedding Model ప్రతి word, sentence లేదా document ని numbers రూపంలో represent చేస్తుంది. ఆ numbers collection నే Vector Embedding అంటారు.

Vector Database ఈ embeddings ని store చేస్తుంది.
