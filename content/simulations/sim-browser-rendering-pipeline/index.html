Web Platform Foundations

From HTML to pixels.

A browser turns source files into a visible page through five connected stages. Each stage produces information the next stage can use.

1

Parse

HTML becomes the DOM and CSS becomes the CSSOM.

2

Style

Selectors and inheritance resolve into computed styles.

3

Layout

The browser calculates each visible box's size and position.

4

Paint

Text, colors, borders, and shadows become drawing commands.

5

Composite

Layers combine on the GPU to create the final frame.

Why this matters

Changing layout-affecting properties can repeat style, layout, paint, and composite work. Transform and opacity changes can often stay in the compositor.
