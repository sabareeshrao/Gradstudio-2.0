# Content library

This directory is intentionally empty of educational content. Add only new founder-requested content after the schemas and validation pass. Never copy legacy GradStudio content here.

Canonical source locations are:

- `categories/<stable-id>/category.json`
- `courses/<stable-id>/course.json`
- `sections/<stable-id>/section.json`
- `shared/<stable-id>/asset.json` and declared public shared assets
- `simulations/<stable-id>/simulation.json`, entry point, and local assets

Folder names are organizational. Manifest IDs are immutable identity.
